# F1 qualification package

This directory contains the human-run command contract and small evidence
templates for the F1 qualification profile. Compiled programs, tests, bucket
artifacts, checkpoints, and blueprints must be executed or generated by a
human operator. The finalizer only reads existing reports and publishes a
passing report when every predicate is satisfied.

Expected evidence layout:

```text
artifacts/f1_dev_v1/<config-fingerprint>/
  buckets/inspection.json
  continuous/training_report.json
  resumed/training_report.json
  qualification/checkpoint_equivalence.json
  qualification/lookup_report.first.json
  qualification/lookup_report.second.json
  qualification/final_acceptance.json
```

Before any production workflow, the human operator records the candidate
commit, toolchain, and build/test logs. Run from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\codex_powershell.ps1 `
  cmake -S . -B build `
  -DTEXASSOLVER_BUILD_TESTS=ON `
  -DTEXASSOLVER_BUILD_EXAMPLES=ON `
  -DTEXASSOLVER_BUILD_RESEARCH_EXAMPLES=ON `
  *> artifacts\f1_dev_v1\build.stdout.log

powershell -ExecutionPolicy Bypass -File scripts\codex_powershell.ps1 `
  cmake --build build --config Release `
  *> artifacts\f1_dev_v1\build.release.stdout.log

powershell -ExecutionPolicy Bypass -File scripts\codex_powershell.ps1 `
  ctest --test-dir build -C Release --output-on-failure `
  *> artifacts\f1_dev_v1\ctest.stdout.log
```

Record each command's exit code and preserve stderr separately when the shell
environment supports it. Use [human_run_record.template.yaml](human_run_record.template.yaml)
for every compiled execution. The expected registered-suite result is 106/106
tests passed for the current candidate; a human must verify and record the
actual result.

Build and test commands are documented in the F1 implementation plan. Preserve
the exact command, exit code, timestamps, compiler identity, commit, stdout,
stderr, and machine report in the evidence directory.

After the reports exist, the human may run:

```powershell
.\build\Release\texas_multiway_finalize.exe `
  --bucket-report artifacts\f1_dev_v1\<fingerprint>\buckets\inspection.json `
  --training-report artifacts\f1_dev_v1\<fingerprint>\continuous\training_report.json `
  --equivalence-report artifacts\f1_dev_v1\<fingerprint>\qualification\checkpoint_equivalence.json `
  --lookup-first artifacts\f1_dev_v1\<fingerprint>\qualification\lookup_report.first.json `
  --lookup-second artifacts\f1_dev_v1\<fingerprint>\qualification\lookup_report.second.json `
  --operator <operator> --start-utc <start> --end-utc <end> `
  --command <exact-command> --machine-report <machine.json> --exit-code 0 `
  --output artifacts\f1_dev_v1\<fingerprint>\qualification\final_acceptance.json
```

Do not edit generated reports to make a predicate pass. Failed or incomplete
evidence remains unqualified and must be rerun by the human operator.
